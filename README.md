# AVR Cable TV - Website

A modern, responsive website for AVR Cable TV featuring premium entertainment services.

## Features

✨ **Modern Design**
- Clean, professional interface with gradient backgrounds
- Responsive design that works on all devices (mobile, tablet, desktop)
- Smooth animations and transitions

📱 **Key Sections**
- **Home (Hero)**: Eye-catching landing section with call-to-action
- **Services**: Showcase of offered services with icons
- **Plans**: Three-tier pricing plans (Basic, Premium, Elite)
- **About**: Company information and statistics
- **Contact**: Contact form and business information
- **Navigation**: Sticky header with smooth scrolling

⚡ **Interactive Features**
- Mobile-responsive hamburger menu
- Smooth scroll navigation
- Plan selection with alerts
- Contact form with validation
- Scroll animations for visual appeal
- Active navigation highlighting

## How to Use

### 1. **Open the Website**
   - Open `index.html` in any modern web browser
   - The website will display with full functionality

### 2. **Navigation**
   - Use the navigation menu at the top to jump between sections
   - Click "Home", "Services", "Plans", "About", or "Contact"
   - On mobile devices, click the hamburger menu icon (☰)

### 3. **Select a Plan**
   - Click any "Select Plan" button to choose a pricing option
   - You'll receive an alert and be taken to the contact form

### 4. **Contact**
   - Fill out the contact form with your details
   - Submit to get in touch with the company
   - Form includes validation for all required fields

## Customization

### Change Company Information
Edit the following in `index.html`:
- **Address**: Around line 158 in the Contact section
- **Phone**: Around line 163 (tel link)
- **Email**: Around line 168 (mailto link)
- **Hours**: Around line 173

### Update Pricing Plans
Edit the Plans section to modify:
- Plan names and prices
- Features lists
- Plan descriptions

### Modify Services
Edit the Services section to change:
- Service icons (emoji)
- Service titles and descriptions
- Number of services

### Adjust Colors
Key colors in `styles.css`:
- Primary: `#667eea` (Purple)
- Secondary: `#ff6b6b` (Red)
- Dark: `#1a237e` (Navy)

Change these hex values to customize the color scheme.

### Update Content
All text content can be directly edited in `index.html`. Simply find the section and modify the text.

## Features Explained

### 1. **Sticky Navigation**
The header stays at the top when scrolling, providing easy access to all sections.

### 2. **Mobile Menu**
On smaller screens, the navigation links hide under a hamburger menu for space efficiency.

### 3. **Plan Card Highlighting**
The Premium Plan is highlighted with a border and slightly larger size to draw attention.

### 4. **Form Validation**
The contact form validates that all fields are filled before submission.

### 5. **Scroll Animations**
Service cards, plan cards, and statistics animate in when they come into view.

### 6. **Smooth Scrolling**
All navigation links smoothly scroll to their target sections.
